# A Mirror of My Becoming™ — ask / getdoc™

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23304513.svg)](https://doi.org/10.5281/zenodo.23304513)

- **ask** — hybrid retrieval in one pass: vector search (meaning) + direct SQL over msgvault.db (entities, dates) + a local LLM (granite) that answers only from the corpus — `NOT IN CORPUS` when it isn't.
- **getdoc** — whole-document reconstruction from the vector store: the way it went in, with its own receipt printed.

Part of [A Mirror of My Becoming™](https://github.com/qaevelyn/a-mirror-of-my-becoming) — Suite. Orchestration layer: [Suite: Overseer™](https://github.com/qaevelyn/a-mirror-of-my-becoming-suite-overseer). Paper: [The Missing Link](https://qaevelyn.github.io/white-papers/the-missing-link/).
